# Плани підземного паркінгу — Вигода / ЖК Lakeview

2-сторінковий A3 PDF з планами паркінгу (рівні −2 та −1, 138 машиномісць)
у фірмовому стилі **Вигоди**.

## Збірка

```bash
python3 -m venv .venv && ./.venv/bin/pip install pymupdf
./.venv/bin/python tools/build-parking-pdf.py
# → tools/parking/Lakeview-parking-plan.pdf
```

Шляхи за замовчуванням беруться з репозиторію; за потреби:
`build-parking-pdf.py <src.pdf> <template.pdf> <out.pdf>`

## Звідки що береться

| Джерело | Роль |
|---|---|
| `tools/parking/src-2020-VVEL-parking-REV02.pdf` | креслення ARCHICAD, лист. 2020, ЖК «Pictorial» / Rubicon Group |
| `img/plans/commercial/_pdf-source/*/01.pdf` | шаблон стилю Вигоди — з нього векторно виймається логотип |

Логотип **не хардкодиться**: він щоразу виймається з архітекторського
шаблону, тому оновлення шаблону автоматично підхоплюється.

## Що робить скрипт

**Видаляє** (повністю, не «замальовує»): золоту плашку та заголовок
GothamPro, знак і напис PICTORIAL, логотип RUBICON GROUP, рядок
`ЛИСТОПАД 2020 | REV.02`, `page 01`, штамп `GSPublisherVersion`, старий
дисклеймер.

**Додає**: навігаційну навіси Вигоди (#2F3640 + лаймова лінія #C1F33D),
векторний логотип, лаймовий заголовок `Рівень −2 / Підземний паркінг`,
новий підвал (дисклеймер, ред./дата, аркуш, контакти).

**Не торкається**: жодної лінії креслення, усіх 138 номерів місць,
розмірів, підписів `74 м/місць`, компаса, схеми секцій.

## Ключові рішення

- **Навіси на самому верху (y=0), без верхнього відступу.** Пропорційно
  масштабована навіси (×√2 від A4) перекрила б стрілку півночі на y=89.
  Повнокровна навіси зберігає всі інші фірмові пропорції точно й дає
  3,4 мм просвіту. Змінюється однією константою `BAND_TOP`.
- **Логотип re-emit'иться як сирі векторні операції, а не через
  `show_pdf_page`.** Клоноване вставляння сторінки тягне за собою **всю**
  сторінку-шаблон: дані комерційних приміщень («Комерційне приміщення»,
  «Санвузол», «Загальна площа») лишалися невидимими, але видобувними через
  `pdftotext`. Перевірено й закрито.
- **`Shape.finish(closePath=True)` не годиться** — закриває лише останній
  підшлях, через що всі внутрішні контури літер («о», «д», кільце)
  зливаються в пляму. Тому `h` на кожен підшлях + один `f*`.
- **Латинська `C1–C4` → кириличні `С1–С4`** (U+0421). Це лише нормалізація
  гомогліфа, нумерація секцій не змінювалась.
- Друкарський мінус U+2212 у `−2` / `−1`, а не дефіс.
- GothamPro (шрифт попереднього бренду) вилучено повністю — і як бренд, і як
  ліцензійний ризик. Усе креслення й так було в Arial, як і шаблон Вигоди.

## Перевірки перед відправкою

```bash
pdftotext Lakeview-parking-plan.pdf - | grep -inE "pictorial|rubicon|GSPublisher|комерц|листопад"
pdffonts Lakeview-parking-plan.pdf | grep -i gotham    # має бути порожньо
```
Плюс: усі 138 номерів присутні, 0 слідів кольорів попереднього бренду.

`tools/build-catalog-slides.py` збирає 4 нові слайди 1920×1080 для презентації
«План квартир Lake View» (Canva `DAHRdS9iang`, 26 сторінок):

| # | Слайд | Джерело |
|---|---|---|
| A | Титульний | рендер `img/renders/aerial.jpg`, кроп 3:2→16:9 `(0,160,2400,1510)` |
| B | Розділювач «ПІДЗЕМНИЙ ПАРКІНГ» | еталонний розділювач каталогу із заклеєною текстовою зоною |
| C | Рівень −2, 74 місця, №1–74 | `Lakeview-parking-plan.pdf` стор. 1, кліп `(26,84,932,730)` |
| D | Рівень −1, 64 місця, №75–138 | те саме, стор. 2 |

```bash
./.venv/bin/python tools/build-catalog-slides.py --refs tools/parking/slides/_refs
```

**Виходи**
- `Lakeview-catalog-additions.pptx` — **основний**. Canva імпортує PPTX як
  редагований дизайн: увесь текст лишається текстом, тож будь-хто потім міняє
  рівень, кількість місць, дату чи контакти прямо в Canva.
- `slides/*.png` — підкладки (фон без тексту), `slides/*-flat.png` — те саме
  із запеченим текстом (запасний варіант і матеріал для візуальної перевірки).

**Як вставити в каталог** (≈2 хв): перетягнути `.pptx` на головну Canva → відкрити
каталог → бічна панель **Projects** → знайти імпортований дизайн → клікнути потрібні
сторінки, вони додадуться в кінець → перетягнути в порядку: титул на початок,
блок паркінгу після 3-кімнатних.

### Чому саме так
Canva MCP не вміє створювати сторінки й не створює нових елементів на порожній
сторінці: `perform-editing-operations` дає лише правку наявних (`replace_text`,
`update_fill`, `insert_fill`, `position_element`, `resize_element`, `format_text`…),
а `upload-asset-from-url` вимагає **публічного** HTTPS-URL. Тому шлях «згенерувати
редагований файл → імпорт → копіювання сторінок» — єдиний, що дає і точність, і
редагованість, не публікуючи файли клієнта в інтернет.

### Ключові рішення
- **Геометрія не вигадана**: знята піпеткою з PNG-експортів самої презентації
  (`slides/_refs/`). Панель від `x=1274`, контент-колонка `1362…1830`, лого
  `1351,69 · 490×145`, лінійки `y=670/908/974`, смуга дисклеймера `y=972, h=108`.
- **Гарнітура підтверджена документально**: PPTX-експорт каталогу містить рівно
  `Montserrat` + `Montserrat Medium`. Вендорна копія — `tools/parking/Montserrat.ttf`
  (OFL), потрібна для растрового варіанта й для перевірки переносів.
- **Полотно PPTX = 18288000×10287000 EMU** — байт-у-байт як експорт Canva
  (1920×1080 @96 dpi), тому сторінки лягають без перерахунку масштабу.
- **Кліп креслення обривається на y=730**, а не 799: нижче — власний підвал
  A3-аркуша, інакше дисклеймер дублювався б двічі на одному слайді.
- **Ліве поле біле.** Кремовий відтінок (#FEEEBD) в еталоні — це заливка кімнат
  усередині креслення, а не тло сторінки.
- **Контраст дисклеймера виправлено**: в еталонному каталозі це світлий текст на
  #D3D7DD = **1,37:1** (фактично нечитний текст під заявою «не є публічною
  офертою»). На нових слайдах — той самий фон, але текст #4A515C = **5,5:1**.
  Решту 26 сторінок це не змінює; варто виправити окремим проходом.
- **Логотип** вийнято з еталонної панелі й розкейовано в прозорий PNG; на титулі
  лежить на скримі щільністю ≥0,76, не на «сирому» рендері.

### Автоматичні гейти перед видачею
Скрипт завершується помилкою і **не віддає файли**, якщо:
- будь-яка з 9 текстових зон не тримає контраст WCAG AA 4,5:1
  (рахується проти найсвітлішого пікселя зони, тобто найгірший випадок);
- дисклеймер після переносу не вміщується у смугу 108 px.

## Відкриті питання до замовника

1. **Права на креслення.** Зняття логотипа Rubicon не передає авторські
   права. Потрібне письмове підтвердження від архітектора, що Вигода може
   використовувати й ребрендувати це креслення.
2. **Актуальність планування 2020 року.** Публікація 6-річного креслення під
   датою 2026 — ризик, якщо щось змінилося. Потрібен підпис архітектора.
3. **Звірка нумерації 1–138** з актуальним реєстром продажів (у проєкті вже
   були помилки такого класу — кв.244, кв.133).
4. **Місця для людей з інвалідністю** — за ДБН мають бути позначені й
   виключені із загальної продажі. На кресленні не позначені.
5. **Дозвільна документація** — чи обидва рівні та 138 місць у межах чинного
   дозволу.
